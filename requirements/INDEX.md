## 如何使用

### 创建新需求

使用 `/plan` 命令创建新需求：

```
/plan [描述你的功能需求或项目目标]
```

示例：
```
/plan Implement resume upload functionality with PDF parsing and AI analysis
```

这将创建一个结构化的需求文档，包括：
- 功能描述
- 验收标准
- 实现计划
- 进度追踪

### 链接 GitHub Issue

在需求创建后，将相关的 GitHub Issue 链接到需求文档中，便于追踪。

### 更新需求状态

当需求进展时，更新相应的需求文档中的状态和完成百分比。

## 需求分类

### 按优先级

**P0 - 关键 (Blocking)**
- 影响系统可用性
- 必须完成

**P1 - 高 (Important)**
- 影响核心功能
- 应该完成

**P2 - 中 (Normal)**
- 增强功能
- 可以完成

**P3 - 低 (Nice to Have)**
- 优化和改进
- 按需完成

### 按类型

| 类型 | 描述 | 示例 |
|------|------|------|
| 功能 | 新增功能特性 | 简历分析、面试评估 |
| 改进 | 优化现有功能 | 性能优化、UX 改进 |
| 修复 | 错误修复 | 路由 404、DB 连接 |
| 技术债 | 代码质量、重构 | 测试覆盖率、文档 |
| 文档 | 文档相关 | API 文档、教程 |
