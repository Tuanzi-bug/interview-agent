## 项目架构理解

### 总体架构
```
前端层 (Next.js + React)
  ↓
API网关层 (Hertz)
  ↓
服务层
  ├── 用户服务 (Hertz)
  ├── 面试管理服务 (Hertz)
  ├── 简历分析服务 (Eino + Hertz)
  ├── 题库管理服务 (Hertz)
  ├── AI交互服务 (Eino + Hertz)
  └── 评估报告服务 (Eino + Hertz)
  ↓
数据层
  ├── MySQL (用户、面试记录等结构化数据)
  ├── Redis (缓存、会话管理)
  └── 对象存储 (简历文件)
```

### 前后端交互模式
- **RESTful API**：主要交互方式
- **数据格式**：统一JSON格式，支持嵌套数据结构
- **认证机制**：JWT token认证
- **错误处理**：统一错误码和错误信息格式
- **状态管理**：前端状态与后端数据同步策略
